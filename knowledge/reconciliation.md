# Conciliaciones SFTP (ejemplo ficticio)

Proyecto: DemoShop
Área: Operaciones

El proceso demo-reconciliation recibe archivos diarios mediante SFTP.
Horario de recepción: 02:00 America/Bogota.
Validación de solo lectura: comprobar fecha, tamaño y checksum del archivo recibido.
No borrar, reenviar ni modificar archivos durante el diagnóstico.
La documentación no define servidor ni credenciales.
